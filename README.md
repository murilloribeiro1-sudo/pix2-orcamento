# PIX2 — Sistema de Orçamento

Sistema web de geração de propostas comerciais para PIX2 Produção de Conteúdo / PIX2 Criação de Conteúdos.

## Funcionalidades

- Briefing completo do projeto
- Configuração de equipe técnica com diárias
- Cálculo automático de cachê, markup e NF
- Preview da proposta em tempo real
- Download em PDF (versão detalhada e versão fechada)

## Stack

- HTML + CSS + JS puro (sem dependências)
- Fontes: DM Mono + Syne (Google Fonts)
- Deploy: Vercel (estático)

## Como usar

Acesse a URL do deploy e preencha os campos. O sistema calcula automaticamente e gera o PDF no browser.
